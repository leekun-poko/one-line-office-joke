A single-line office joke, written by a small Python program: the office printer has claimed to be low on toner since March, yet it printed all 42 pages of the fantasy football draft without blinking — the toner, the program concludes, is only afraid of spreadsheets. The program writes the joke to /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt when that variable is set).

## Run it

```sh
python3 main.py
```
